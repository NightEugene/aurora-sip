# Аврора SIP

Нативный SIP-телефон для ОС Аврора 5.2.1+ с поддержкой FreePBX и других совместимых АТС.

## Возможности

- Один SIP-аккаунт, подключение по TLS и автоматическое восстановление соединения.
- Аудиозвонки, тональный набор DTMF, отключение микрофона и громкая связь.
- Обычный RTP для аудио по умолчанию; требование SRTP включается в настройках аккаунта.
- Сохранение аккаунта и пароля с помощью Aurora Keystore.
- История звонков с длительностью разговора и именами контактов.
- Контакты из каталога Yealink XML по HTTP/HTTPS или из локального файла.
- Локальная копия каталога, поиск по имени и номеру, избранные контакты.
- Поиск в AppBar, обновление контактов жестом pull-to-refresh, звуки клавиш и виброотклик.

Для звонков необходимы SIP-учётная запись и доступ к АТС. Системная адресная книга
телефона не используется. Возможность одновременной работы нескольких устройств
с одним аккаунтом определяется настройками АТС. Постоянный приём вызовов в фоне
зависит от ограничений ОС и не гарантируется.

## Компоненты

- **C++ и Qt/QML** — логика приложения и пользовательский интерфейс.
- **Aurora Controls и Sailfish Silica** — AppBar, навигация, списки и pull-to-refresh.
- **PJSIP / PJMEDIA** — SIP-сигнализация и обработка аудио. Подключён Git-сабмодулем
  [third_party/pjproject](https://github.com/pjsip/pjproject) и линкуется статически.
  Закреплена ревизия `c0261ff0bf94a3f7bd67661573597dafe69725be` ветки upstream 2.17-dev.
- **Aurora CallService** — интеграция звонков и управление аудиомаршрутами.
- **QCA и Aurora Keystore** — защита пароля и параметров аккаунта с помощью AES-256-GCM.
- **OpenSSL** — TLS и проверка сертификатов через системное хранилище доверия.
- **NGF** — звуки набора и тактильная обратная связь.
- **Qt Network и XML** — загрузка и разбор каталога контактов.

### TLS-патч PJSIP

В [patches/pjsip-tls-hostname.patch](patches/pjsip-tls-hostname.patch) изменена проверка
имени сервера: вместо буквального сравнения PJSIP используется OpenSSL.
Вспомогательная функция находится в [patches/aurora_tls_identity.h](patches/aurora_tls_identity.h).

Это позволяет использовать сертификаты с wildcard-именами, например `*.example.org`.
Подстановка охватывает только один уровень DNS; также проверяются SAN и IP-адреса.
Проверка доверия к цепочке и срока действия сертификата остаётся обязательной.

Патч применяется автоматически при сборке к отдельной копии PJSIP в каталоге сборки.
Исходники сабмодуля при этом не изменяются.
